Format each line as Task description | day-of-month (e.g. Submit report | 28) — this is a permanent, recurring checklist item, set up once. It is NOT tied to a specific month; every month it's simply due again on that day, and staff check it off on the to-do page. If you leave off the "| day" part, day 28 is used. Re-running this for the same department/task text updates the due day instead of duplicating the row.
